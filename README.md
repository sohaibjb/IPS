# Indoor Positioning System (IPS)

Indoor positioning is challenging because GPS signals are generally unavailable or unreliable inside buildings.

This project studies the design and implementation of **Indoor Positioning Systems (IPS)** using radio-frequency technologies. Two distinct localization and tracking concepts were investigated:

- **Bluetooth Low Energy (BLE)** based indoor localization using RSSI measurements, dynamic calibration, distance estimation, and trilateration.
- **UHF RFID** based indoor identification and tracking using passive RFID tags, fixed readers, an ESP8266 communication node, and a server-side data architecture.

The project also includes the design of a custom **ESP32-based IPS-BLE PCB using Altium Designer**, including its power supply, Li-Ion charging, and battery protection circuits.
